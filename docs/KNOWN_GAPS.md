# Known Gaps

Items intentionally deferred. Each is either hidden in the UI or clearly disabled with an explanation.

## Brand

- **Favicon/Logo**: No brand icon. User to supply source image (SVG or 1024x1024 PNG). Framework default icons deleted. Blocks release readiness (Phase 11).

## Features (behind feature flags or not yet implemented)

- **WhatsApp integration**: Feature-flagged. Requires Meta Business verification and approved templates.
- **Billing/Subscription**: Feature-flagged. Requires Razorpay/Stripe account setup.
- **RAG over documents**: Planned for Phase 9. Basic version after core is stable.
- **Dark mode**: Design tokens defined for light mode only in MVP. Dark mode planned post-MVP.
- **Forecasting**: Only when sufficient historical data exists.
